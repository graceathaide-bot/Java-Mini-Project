# 🎮 Brick Breaker

A Java-based Brick Breaker game developed as a mini project using **Java** and **NetBeans IDE**.

The game is based on the classic Brick Breaker concept where the player controls a paddle to bounce a ball and break all the bricks.

---

## 📌 Project Overview

Brick Breaker is a simple 2D arcade game developed using Java.

The player controls a paddle at the bottom of the screen and uses it to bounce the ball. The objective is to break all the bricks using the ball while preventing the ball from falling below the paddle.

This project was developed as a **Java Mini Project** to apply concepts of object-oriented programming, event handling, GUI development, and game logic.

---

## ✨ Features

- 🎮 Paddle movement using keyboard controls
- ⚽ Ball movement and bouncing
- 🧱 Brick-breaking mechanics
- 💯 Score tracking
- ❤️ Lives / game-over functionality
- 🏆 Win condition after breaking all bricks
- 🖥️ Graphical user interface
- 🔄 Restart / replay functionality

## 🎯 How to Play

1. Launch the game.
2. Use the **Left Arrow** and **Right Arrow** keys to move the paddle.
3. Keep the ball from falling below the paddle.
4. Break the bricks using the ball.
5. Continue until all the bricks are destroyed.
6. Try to achieve the highest possible score!

---

## ▶️ How to Run the Project

### Step 1: Download the Project

Download the **NeonBrickBreaker ZIP file** from this repository.

### Step 2: Extract the ZIP

Extract the downloaded `.zip` file to a suitable location on your computer.

### Step 3: Open in NetBeans

1. Open **NetBeans IDE**.
2. Go to **File → Open Project**.
3. Select the extracted **Brick Breaker project folder**.
4. Click **Open Project**.

### Step 4: Run the Game

1. Locate the main Java class.
2. Right-click the project.
3. Select **Run** or press **F6**.
4. The Brick Breaker game will launch.

> **Note:** Make sure Java JDK and NetBeans IDE are installed on your computer before running the project.
